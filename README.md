# FlexiDrive | Portal de Arquitectura Empresarial

Activo digital del proyecto final de Arquitectura Empresarial (Universidad Libre, Seccional Barranquilla, 2026).

**Portal:** https://gabrieldevco.github.io/flexidrive/

Sitio estático en HTML, CSS y JavaScript que permite explorar la arquitectura empresarial de FlexiDrive: estrategia, negocio (simulador del proceso de alquiler), información, aplicaciones, tecnología y transformación.

## Estructura

- `index.html`: contenido de las ocho secciones
- `css/estilos.css`: diseño
- `js/datos.js`: datos de la arquitectura
- `js/app.js`: interacción
- `img/`: logos y diagramas
